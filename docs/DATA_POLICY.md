# Data Policy

GeoRisk is designed for reproducible analysis from small, auditable repository
inputs. Public releases should include derived summaries and evaluation
artifacts, not raw collected source dumps or redistributable-unclear market
data.

## Public Repository Data

Keep these data components in the public repository when they are needed for
runtime behavior or canonical evaluation:

- `data/historical_cases.json`: curated, concise historical case summaries.
- `data/asset_mapping.csv`: curated candidate asset mapping.
- `data/transmission_context_v1.json`: generated transmission-context sidecar.
- compact benchmark manifests, summaries, and final evaluator CSVs needed to
  trace reported V4/V5 metrics.

These files should be treated as analytical/derived project data. They are not
investment recommendations and do not authorize redistribution of third-party
source text beyond the concise derived summaries already present.

## Excluded Raw Candidate Data

Raw candidate/source dumps are excluded from public release:

- `data/validation_candidates/raw/`
- `data/validation_v3/candidates/raw/`
- `data/validation_v3/candidates_2019_2024/raw/`
- non-placeholder files under `data/validation_v4/candidates/raw/`

These files may contain scraped metadata, copied source snippets, URL tokens,
or provider-specific fields whose redistribution terms are unclear. Public
benchmarks should use concise event descriptions with source citations instead.

## Excluded Market Price Data

Downloaded market price files are excluded from public release unless their
provider terms explicitly allow redistribution:

- `data/prices/`
- `data/eval/*prices*.csv`
- `data/market_validation/**/prices/`

Market-validation summaries and templates may remain public. Full price inputs
should be regenerated by users locally with the provided scripts and their own
network/data-provider access.

## Chroma / Model Artifacts

`chroma_db/` and Chroma backup directories are generated local runtime state.
They should not be committed. Rebuild the index from public source data:

```bash
python -m src.vector_store_health --rebuild
```

The embedding model is `sentence-transformers/all-MiniLM-L6-v2`. Runtime
defaults to local-only model loading for frozen-test stability. On a clean
machine, copy `.env.example` to `.env` or export
`GEORISK_LOCAL_MODEL_FILES_ONLY=false` before rebuilding the index so
`sentence-transformers` can download the model once.
